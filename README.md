🤖 Bot Discord - Controle de Pings

Bot para controle de pings por categorias (loja, anúncio, leilão e parceria), com sistema de limite e punição automática.

---

🚀 Funcionalidades

- Controle de pings por cargo
- Sistema de limite automático
- Log de pings
- Punição (timeout) ao ultrapassar limite
- Comando "!pings" para ver uso

---

⚙️ Tecnologias

- Node.js
- discord.js v14
- Express

---

▶️ Como rodar

1. Instale as dependências:

npm install

2. Crie uma variável de ambiente chamada "TOKEN" com o token do bot

3. Inicie o bot:

npm start

---

🌐 Hospedagem

Este bot pode ser hospedado no Render usando integração com GitHub.

---

📌 Observações

- Certifique-se de que o bot tem permissão de:
  - Enviar mensagens
  - Timeout (moderar membros)
- Ative as intents no painel do Discord Developer Portal:
  - Message Content Intent
